### СПРАВКА

ReLU (Rectified Linear Unit) — функция активации в машинном обучении (ML), которая широко используется в глубоком обучении. Выступает в роли математического привратника внутри нейронной сети: определяет выход нейрона с помощью простого нелинейного преобразования. 

sigmoid - это гладкая монотонно возрастающая нелинейная функция, которая имеет характерную S-образную форму. Она преобразует любое вещественное число в диапазон от 0 до 1, что делает её полезной в задачах, где требуется интерпретировать результат как вероятность.

tanh (гиперболический тангенс) — функция активации в машинном обучении, которая преобразует входные значения в выходные в диапазоне от –1 до 1.

softmax - математическая функция в машинном обучении (ML), которая преобразует вектор исходных чисел (логитов) в вектор вероятностей. Это обобщение логистической функции для многомерного случая.

linear - это статистический метод моделирования зависимости одной переменной (зависимой, объясняемой, целевой) от одной или нескольких других переменных (независимых, факторов, регрессоров) с использованием линейной функции. Метод позволяет предсказывать значения зависимой переменной на основе известных значений независимых переменных.

Xavier/He - методы инициализации весов в нейронных сетях. Оба решают одну и ту же задачу: сохранить дисперсию сигнала и градиента при распространении по слоям нейросети.

Xavier - работает с функциями активации, которые симметричны вокруг нуля и имеют производную, близкую к 1, например с гиперболическим тангенсом (tanh) или логистической сигмоидной функцией. Инициализация Xavier позволяет обучать глубокие полносвязные сети с десятками слоёв без катастрофических ошибок.

He - предназначен для функции активации ReLU и ее вариантов (например, Leaky ReLU, PReLU). Поскольку ReLU отбрасывает отрицательные значения, He-инициализация компенсирует это, удваивая дисперсию по сравнению с одной из формул Xavier.
